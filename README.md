# 熊本支援情報

2026年7月熊本地震で被災した方が、利用できる可能性のある支援を短時間で探し、公式情報へ進むための非公式まとめサイトです。

## 方針

- 修理前の写真、り災証明書、修理代支払い前の相談を最上部で案内
- 困りごと別に支援情報を絞り込み
- 各制度を「こんな人」「どうなる？」「注意」で統一
- 一次情報へのリンクとURLコピーボタンを掲載
- スマートフォン、ダークモード、印刷、キーボード操作に対応
- 外部ライブラリや画像を使わず、災害時の通信量を抑制

## 注意

このサイトは行政機関の公式サイトではありません。制度の対象条件、期限、必要書類、受付状況は変更される場合があります。申込みの前に、必ずリンク先の公式サイトや担当窓口で最新情報を確認してください。

## ローカル確認

静的サイトのため、`index.html` をブラウザで開くか、任意のローカルHTTPサーバーで配信してください。
