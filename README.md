# 熊本支援情報

2026年7月熊本地震で被災した住民・事業者と、復旧工事に入る会社や現場の人が、利用できる可能性のある支援を短時間で探し、公式情報へ進むための非公式まとめサイトです。

## 方針

- 修理前の写真、り災証明書、修理代支払い前の相談を最上部で案内
- 困りごと別に支援情報を絞り込み
- 各制度を「こんな人」「どうなる？」「注意」で統一
- 一次情報へのリンクとURLコピーボタンを掲載
- スマートフォン、ダークモード、印刷、キーボード操作に対応
- 外部ライブラリや画像を使わず、災害時の通信量を抑制
- Pull RequestごとにHTML、内部リンク、表示件数、期限、公式URLを自動確認
- 毎日、掲載中の外部リンクと期限を自動確認

## 注意

このサイトは行政機関の公式サイトではありません。制度の対象条件、期限、必要書類、受付状況は変更される場合があります。申込みの前に、必ずリンク先の公式サイトや担当窓口で最新情報を確認してください。

## ローカル確認

静的サイトのため、`index.html` をブラウザで開くか、任意のローカルHTTPサーバーで配信してください。

公開前の検査は `python .github/check-site.py --nu`、外部リンクを含む検査は `python .github/check-site.py --external-links` で実行できます。
